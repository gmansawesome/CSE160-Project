Show all docker containers:
    docker ps -a 

Remove docker container:
    docker rm <container_name>

Show all docker images:
    docker images

Run docker image:
    docker run -ti <image_name>

Run docker image and mount local folder:
    docker run -v <local_folder_path>:<destination_in_TinyOS> -ti <image_name>
    docker run -v C:\Users\micha\Documents\CSE160-Project:/home/CSE160 -ti ucmercedandeslab/tinyos_debian
